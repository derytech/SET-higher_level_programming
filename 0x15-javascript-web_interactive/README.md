# JavaScript - Web Interactivity

## Description

This project focuses on learning JavaScript for web development, with an emphasis on making websites interactive and dynamic. It explores how JavaScript interacts with HTML elements, manipulates the Document Object Model (DOM), handles user events, and updates webpage content without reloading the page.

The exercises are designed to build practical skills in client-side JavaScript using vanilla JavaScript.

## Learning Objectives

By completing this project, I aim to learn how to:

* Manipulate HTML elements using JavaScript.
* Modify element styles and webpage content dynamically.
* Handle events and user interactions.
* Select and update DOM elements.
* Use JavaScript to make web pages interactive.
* Fetch and process data where required by the exercises.
* Follow JavaScript coding standards and best practices.

## Requirements

* Use vanilla JavaScript only.
* Do not use `var`.
* Do not import jQuery or any other external library.
* Ensure all files end with a newline.
* Use a modern web browser to test the JavaScript code.
* Include a `README.md` file at the root of the project directory.
